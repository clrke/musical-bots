How to run it

Your key stays in this browser: in this tab's sessionStorage, and in this device's localStorage only if you tick Remember. It is sent once, over HTTPS, with this run. The server never stores or logs it: it goes only into the environment of this run's sandbox, which is destroyed when the run ends.
